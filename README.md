# Alfík · Učiteľský portál

## GitHub Pages

1. Nahraj obsah tohto priečinka do GitHub repozitára
2. Nastav **Settings → Pages → Deploy from branch → main / (root)**
3. Aplikácia beží na `https://<username>.github.io/<repo-name>/`

## Navigácia

| Screen | Popis |
|---|---|
| 1A · Prehľad triedy | Dashboard s odznakmi a štatistikami |
| 1B · Knižnica | Materiály podľa tém, ŠVP, typov a vlastné |
| 1C · Moje hodiny | Zoznam hodín zoskupený do lekcií |
| 1D · História | Zoznam prehratých cvičení |
